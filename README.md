A tiny program that writes one romantic pickup line for a robot, flirting in the language of machine learning: the speaker compares the machine to the very thing that measures how wrong it is, then admits that every round of retraining only pulls it closer. One line, one file, no dependencies.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

This writes the line to `./out/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set, defaulting to `/output/entry.txt`).
